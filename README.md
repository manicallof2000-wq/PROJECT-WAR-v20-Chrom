# City Drive 🚗

یک بازی سه‌بعدی مرورگری برای رانندگی آزاد و خریدوفروش ماشین.

## اجرا
فایل `index.html` را با یک مرورگر مدرن باز کنید. برای بارگذاری Three.js اتصال اینترنت لازم است.

## کنترل‌ها
- حرکت: WASD یا کلیدهای جهت‌دار
- گاز موبایل: دکمه Shift
- ترمز/دنده عقب: Space یا فلش پایین
- تغییر دوربین: C یا دکمه «تغییر دوربین»
- گاراژ: G یا دکمه «گاراژ»

## امکانات نسخه شروع
- شهر سه‌بعدی ساده
- رانندگی با دوربین تعقیبی و کابین
- نمایشگاه، خرید، انتخاب و فروش ماشین
- ذخیره پیشرفت در نشست فعلی بازی

این نسخه پایه است و در مراحل بعدی می‌توانیم شهر، مدل ماشین‌ها، صدا، مأموریت‌ها و ذخیره‌سازی پایدار را ارتقا دهیم.
